**Bloom — Brick / Hammer Preview (10/10)**

Tenth month, tenth day. If any day was going to be release day, it was this one.

That was the plan, anyway. Bloom is in its final round of device testing, and we'd rather take a little more time than rush it. So today is a preview: Bloom for the Trimui Brick and Brick Hammer, a first look at what's coming.

**[Download the Brick / Hammer Preview](https://github.com/tenlevels/PakUI/releases/tag/Bloom)**

**Install**

1. Download the Bloom image for the Trimui Brick / Hammer from the [release page](https://github.com/tenlevels/PakUI/releases/tag/Bloom).
2. Write it to an SD card with [Raspberry Pi Imager](https://www.raspberrypi.com/software/) (our pick) or any image writer you like.
3. Put the card in your device and power on. The first boot sets everything up and takes a few minutes. Let it finish.

Writing the image erases the card, so back up anything on it first.
